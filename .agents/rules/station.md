# 清单与页面片段

适用：`station/**`

## 清单

`station/modules.json` 的每一项：

| 字段 | 要求 |
|------|------|
| `id` | 必填。`[a-z0-9-]{1,32}`，全清单唯一。同时是 URL `/<id>/` 和页面文件名 |
| `name` | 必填。导航和页头上的显示名 |
| `group` | 可空。首页用来分组；空则这一项不显示分组标题 |
| `summary` | 可空。首页卡片和模块页页头的一句说明 |
| `status` | 可空。非空时首页显示该徽章；功能可用后删掉整个字段 |

顶层 `name` 是工作台显示名，缺省时用「工作台」。不要往固定字段里塞某个模块的数据。

## 页面文件

- 路径固定为 `station/pages/<id>.html`，文件名与 `id` 一致
- 只写中间内容，不写整页骨架、侧栏或底栏
- 文件开头保留一句注释，说明替换的是这一段、导航来自清单
- 没有该文件是正常状态：服务器显示占位，清单项仍然保留
- 片段可以引用 `/assets/site.css` 里已有的 class；不要在片段里再链一套整页样式

```html
<!-- 替换这一段即可，不要写整页 html。导航来自 station/modules.json。 -->
<section class="placeholder">
  <p class="kicker">准备中</p>
  <h2>功能尚未放入</h2>
  <p>入口已经接好。</p>
</section>
```
