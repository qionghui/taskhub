# 样式约定

适用：`web/assets/**`

- 站点样式只有 `web/assets/site.css`。新外观写进这个文件，不要另起一个样式表，也不要在页面片段里堆整页 `<style>`
- 颜色、字号和表面用文件顶部的变量。新颜色先加变量，再在规则里使用
- 窄屏是默认：顶栏加底栏。`min-width: 900px` 才显示左侧栏，并藏起顶栏和底栏
- 改布局、导航或间距时，两种宽度都要成立。底栏要给正文留出位置，并考虑安全区
- 页面片段优先用已有 class：`placeholder`、`kicker`、`card`、`badge`、`meta`
- 链接和按钮要有可见的焦点样式，沿用现有的 `focus-visible`
- 静态资源响应带 `Cache-Control: no-store`。改完 css 刷新即可，不要靠改查询串来防缓存

## 排版

文字、徽章和卡片必须完整落在可视区域里。侧栏、顶栏、底栏和视口边缘都不能裁到它们。

- 宽屏主栏用 `minmax(0, 1fr)`。`.main`、`.main-inner`、`.card`、`.card-text` 设 `min-width: 0`，列要能缩小，不能被内容的最小宽度撑出视口
- 卡片列用 `minmax(min(100%, 260px), 1fr)`。放不下一列就改成单列并缩小，不要出现横向滚动
- 长文字换行。徽章和「进入」留在卡片里面。不要用 `white-space: nowrap` 把一行撑出容器
- 页头（kicker、标题、说明）上下左右都留出空隙，不能贴着视口或侧栏
- 窄屏底栏是固定的，正文底部的空隙要大于栏高，并加上安全区。顶栏占住自己的高度，滚动前不能盖住页头
